## 二、🚫 windows-mcp 全域一票否决（用户拍板 2026-07-25）

**任何场景不得使用 windows-mcp 的任何工具**——不是「常规场景禁、特殊场景可用」，是**一票否决**。
该 MCP 已从用户机器卸载；`ccswitch/hooks/dao-hard-gates.js` 的 G1 在 PreToolUse `exit 2` 当场阻断，
**无逃生阀**。被拦时 stderr 会直接给出替代分工。

替代分工（记这一行就够，细节在 `dao-gui-verify.md` 与 `stacks/desktop-tauri.md`）：
DOM 与截图 → chrome-devtools / playwright；进程与注册表 → 内置 PowerShell 工具；
文件读写搜索 → 内置 Read / Grep / Glob；纯 Win32 无 Web 层 → PowerShell + .NET 截图脚本，
脚本也不可行时**诚实挂账「需用户目视」**，不得为此复活它。

⚠ **本节是禁令的项目侧转述，措辞上不留任何启用条件**。历史教训：某项目副本写的是
「windows-mcp 仅在 WebView2 CDP 物理不可用时才用」——那句话在母版升级为一票否决之后
仍然活着，于是同一条规则在两个仓有两个强度。**派生本模板时这一节整段照抄，不要"结合项目情况"改写。**

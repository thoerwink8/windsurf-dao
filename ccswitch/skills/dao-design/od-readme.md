# /dao-design — OD 端设计技能

> 用户发送 `/dao-design` 时读这个文件。这是路由入口，不是协议本身。

**第一步**：读取同目录下的 `dao-design-protocol.md`（完整设计协议）。

**第二步**：根据用户参数执行：

| 用户输入 | 行为 |
|---|---|
| `/dao-design` 或 `/dao-design 阅读初始化规则` | 读取协议，进入设计模式，等待设计指令 |
| `/dao-design 审计` 或 `/dao-design 纠错` | 读取协议后立即执行「设计文件审计修复」（协议 §维护命令） |

协议读取后在本会话内持续生效，后续可直接发 `dao-design` 再次触发审计。

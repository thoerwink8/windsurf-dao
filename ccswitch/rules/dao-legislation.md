- **编辑准则**：违例后修条款，只准改形态（进模板/进载荷/进 hook），不准只加叙事——叙事归账本（fortify-20260726）。
- **谁来定这条规矩：按「执行时要不要现场判断」分档，不按大小**（用户 2026-07-27 拍板，原话「小的我自己定，大的才问」，配套原话「我不希望每次我强制提醒，太累了」）。**分界判据不是条款的篇幅或影响面，是执行它的那一刻还需不需要取舍**：
  - **照做档 ⇒ AI 自定**：执行时零现场判断——跑哪个命令、填哪个字段、用什么格式/前缀、写进哪个文件、按什么顺序。**可机械近似的测法**：这条能不能写成一句「动作+对象+时机」的祈使句，且句中不出现程度词与主观量词（充分 / 必要时 / 合适的 / 足够 / 重要的 / 尽量 / 酌情）。出现即不算照做档。**这是近似，两向都有反例**（两向反例各一：见 rationales §反-1）。
  - **判断档 ⇒ 必须问用户**：执行时要现场取舍——什么算够 / 什么时候停 / 要不要换方向 / 删什么留什么 / 哪个优先。
  - **两条否决项优先于上面的祈使句测试**，命中即归判断档，措辞多机械都不行：①**它给 AI 自己定及格线**（验到什么程度算验完、几条算够、什么情况可以跳过）——自己给自己划及格线是结构性利益冲突，与能力无关；②**它改用户可见面或不可逆**（用户会看到的产物形态、删除/发布/改配置源/退役某个入口）。
  - **回溯面是自定档的对价——没有回溯面的自主授权等于不可撤销**：AI 自定的每一条必须①行内带 `[自定@<月日>]` 标记②被某个「每次都会打印一次」的地方汇总（落点示例：条款库统计段，见 mousse `scripts/check-clauses-structure.ps1`）③窗末简报报一个数。用户凭标记随时抽验、凭日期整批撤回（「07-27 之后你自定的全撤」），撤回不需要理由。
  - **刻意偏保守**，因为用户自陈的失败方向就是这一侧（他的原话：「我可能把不该自主的归成自主」）：拿不准归判断档。误判成「该问」只多问一次；误判成「可自定」会静默改变行为且无人知道发生过。 [n=2 @07-27 触发:元字段] [基线:首轮收割 10 条 100% 逐条送用户拍板（dao-growth-loop §四）；按本档回溯分类未做，故「其中本可自定的占比」未测。同类诉求另一次出处：2026-06-16 用户要求 `/dao-distill` 自动化「不需要人为去干预」]
- **立法必带基线数字**：条款括注不能只写「（某日某批实证）」，必须写「入库时基线：该类问题近 N 次同类动作中 M 例」。**没有基线数字的条款，此后不得被引用为「有效」**；写「基线:未测」是允许且诚实的——它让「哪些条款的有效性根本无从判定」一眼可见，而现在这个数字是隐形的。要防的是**归因陷阱**：行为先改好、规则才追认，然后该行为的持续被当成规则的功劳（是「防住了 vs 没机会发生」的镜像错误，更隐蔽；出处：叙事 N9-③）。 [n=1 @07-27 触发:元字段] [基线:「秒级自合」100%→13.5% 的拐点落在 PR #58，治它的条款晚 5 天入库 ⇒ 那 86.5 个百分点与条款无关；同型污染面=出处日期晚于实际拐点的全部条款]

## 射程边界（照直写，别读成全包）

**触发器是作用域档 `ccswitch/rules/scoped/dao-scope-legislation.md`**（2026-08-02 加，与
`dao-powershell.md` / `dao-guard-writing.md` 同型）：源在 git 里，投影落
`~/.claude/rules/dao-scope-legislation.md`，宿主在**Read 到匹配文件**时把「去读本文件」
自动送到眼前。四条 `paths:` 是 `**/dao.md` · `**/ccswitch/rules/**/*.md` ·
`**/docs/rules/dispatch-clauses.md` · `**/.claude/rules/*.md`。当前投影状态随时可查：

```
node ccswitch/scripts/dao-rules-deploy.mjs --check
```

三个已知缺口，一个都别当成已补：

1. 🔴 **跨项目会话未验，这是本档最大的未知**。已实测的机制事实是「glob 按**当前项目根**解析」
   （见 `dao-rules-deploy.mjs` 文件头②），而 dao 的立法动作**大量发生在别的项目的会话里**
   （在 mousse-cli 会话中改 windsurf-dao 的 `ccswitch/dao.md`）。那时 `**/dao.md` 会不会命中
   一个项目根之外的绝对路径——**未实测**。四条 glob 里只有 `**/.claude/rules/*.md` 明显在
   任何项目里都可能命中。**别按「已覆盖」宣称**，它可能只在 windsurf-dao 自己的会话里响。
2. **射程是「Read 到了那份规则集」，不是「立了一条法」**：**从零新建**一份规则集时没有可 Read 的
   旧文件，那一半仍只有 dao.md 反·归节的存根做纯文字兜底。同 `dao-powershell.md`
   「只覆盖改已有脚本、不覆盖从零新建」的缺口。
3. **没有任何程序核「读到了就照做」**：作用域档改的是**送不送得到**，不是「送到了就会做」
   （本仓实测无标记时刻的自由裁量携带率 9-24%，那是投递侧的数；遵守率侧本档**未测**）。

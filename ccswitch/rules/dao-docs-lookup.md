# 查文档走哪条路

**什么时候读**：你正准备去查「某个东西怎么用」——某个库、框架、SDK、API、命令行工具的文档。

**为什么要有这张表**：一个人摸索出来的路传不到下一个人那里，同级之间没有横向通道。
写在这里一次，谁查文档谁先看一眼，不用各自摸索。

## 按你要查什么选路

| 你要查什么 | 走哪条 | 为什么 |
|---|---|---|
| **库 / 框架 / SDK / API / 命令行工具的文档** | **context7 优先** | 它自己的说明里就写着「凡问到库、框架、SDK、API、云服务，用本服务取当前文档，**优先于网页搜索**；哪怕你觉得自己知道答案也用——你的训练数据可能没跟上」。这句话每个会话都注入，本表只是把它搬到看得见的地方。 |
| **GitHub 上的内容**（某个仓的文件、目录树、issue、PR、release） | **`gh api`**，不是 WebFetch | 走已登录的命令行：私有仓也读得到、不吃匿名限流、拿的是原始字节而不是渲染后的页面。取文件：`gh api repos/<o>/<r>/contents/<路径> --jq '.content' \| base64 -d > _tmp/x.md`，再用 Read/Grep 读。 |
| **普通网页**（博客、RFC、任意站点） | **WebFetch** | 大体正常，但不是全通。取不到先换条路再试，别直接跳到重器。 |
| **Claude Code / Claude API 自己的官方文档** | 见下面「一个已知的坑」 | |

## 一个已知的坑：官方文档站可能本机取不到

**这是本机环境的事，不是官方站下线了**——别写成后者去误导别人。
撞上 `Socket is closed` 时两条替代，都免费、都实测可达：

1. **context7 的 `/websites/code_claude`** —— 每条结果带原始出处 URL，可回溯。
2. **GitHub 镜像仓 `pleaseai/claude-code-docs`** —— 用 `gh api` 直接取：

```bash
gh api repos/pleaseai/claude-code-docs/git/trees/main?recursive=1 --jq '.tree[].path'
gh api repos/pleaseai/claude-code-docs/contents/docs/hooks.md --jq '.content' | base64 -d > _tmp/hooks.md
```

该仓自述以官方 `llms.txt` 为真相源、约 6 小时同步一次，下载失败即中止提交（宁可停更也不产生假删除）。
**这是它的自述，没有独立验证过**——涉及版本敏感的结论最好再对一次 context7。

⚠ **旧地址不是替代路径**：它会 301 重定向到同一个取不到的主机上，绕不过去。
WebFetch 对跨主机重定向不自动跟随、会把目标 URL 交回给你——**那个交回来的 URL 正是取不到的那个**。

⚠ **记的是「目标 + 取数方式」这一对，不是主机本身**：同一个主机，`gh api` 这条路通、WebFetch 那条路不通，
是实际发生过的。**换条路再试一次，比断言「这个站挂了」便宜得多。**

## 上面三条都取不到：Firecrawl 的位置

**它解什么**：本机够不着的任意网页——它走自己的服务器抓取，能力是真的。**默认不用。**

| 态 | 行为 |
|---|---|
| 默认 | **不用**。WebFetch / context7 / GitHub 镜像三条免费路打底 |
| 用户主动说「用 Firecrawl」 | 直接用，不再问 |
| 你觉得这次值得用 | **呈用户拍板** |

🔴 **什么时候才准开口提它**：只有上面三条免费路**都实际试过**、且拿不到所需精度时。
提的时候必带三样——**①试过什么**（哪几条路、各自的失败形态）**②缺什么精度**（摘要答不上哪个具体问题）
**③这次预估抓多少页**。**三样答不出就不许提。**

**为什么专门立这一条**：不设它，「强烈推荐」会退化成「每次都推荐」，
而那等于**把默认态偷偷改回去**——默认是「不用」，一个每次都出现的建议会让「不用」名存实亡。

**成本这件事为什么不由 AI 拍**：用户的实际用量是一个月几千次调研级抓取，
在那个量级上免费层根本不成立。这个数字是问出来的，而在问到之前本文件作者估过一次——**差了一个数量级**。
留着这句当判据：**成本类判断默认呈用户**，AI 手里通常没有「用量」这一半的事实，而估错的方向是系统性的（往小里估）。

## 要加任何 MCP 之前

先认清源与投影：**MCP 的真相源是 cc-switch 数据库，`~/.claude.json` 只是投影。**
`claude mcp add` 写的是投影——当场生效，**下次下发即被整体覆盖，且无告警**。
照它做会得到「我明明加过了，怎么没了」，而中间没有任何一步报错。正路是改数据库，那属用户动作。
同族的另外两个面（钩子注册、settings）见 `ccswitch/rules/dao-shell.md` 末节。

## 照直写：这份文件没有机器提醒

「查文档之前先看这张表」这句话只靠记性——那一刻不 Read 任何文件，构造不出触发条件。
表里**只有第一行是有投递的**（context7 那句「优先用我」由它自己每个会话注入，不依赖本文件）。
别把「写下来了」读成「从此有人管了」。

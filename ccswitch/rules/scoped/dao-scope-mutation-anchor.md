# 你正在碰测试文件 —— 如果这一轮要写 / 改「把被测物改坏看断言红不红」，先看这一条

这类验证靠在被测源码里找一段**锚点**再替换掉。锚点没命中时替换会原样返回，
变异体等于原文，**被测守卫照常绿**——而那与「守卫真的没塌陷」逐字节相同。

三件事，动手前先答：

1. **锚点跨行吗？** 跨行才有风险（单行锚点里没有换行，行尾差异咬不到它）。
   跨行就用正则、换行位写 `\r?\n`；**别改用「读进来先归一化行尾」**——那会改变副本内容。
2. **「锚点仍在」的断言，断的是你真正喂给替换函数的那个表达式吗？**
   断言前缀串而替换用正则 = 两个不同的锚，断言会在锚落空时照常通过。
3. **变异体还活着吗？** 一个把靶弄死的变异会让每条断言都红，那正是「判别力满分」的表象。

## 派单令必带首行（canonical 模板 · 原样复制，不要改写、不要判断该不该带）

写派单 prompt 时，**第一行固定是这句**（把两个尖括号换成真路径）：

```
开工第一步：Read `<dao 仓根>/ccswitch/rules/dao-officer-clauses.md`（跨项目通用判据）+ 本仓 `<项目条款库路径>`（本仓特有条款），两份都通读「通用节」+ 你所属官种那一节，逐条遵守。有冲突以盘上文件为准，不以本 prompt 的转述为准。
```

**为什么是两份**（2026-08-02 拆分）：官侧条款分**通用半边**（与技术栈无关的判据，住
`ccswitch/rules/dao-officer-clauses.md` —— 本文件是**帅侧**，那份是**官侧**，两份平级）
与**项目特有半边**（那个仓的验证入口 / 账本文件 / 进程名 / 专有脚本 / 专有标签，
住项目的 `docs/rules/dispatch-clauses.md`）。**只给一份路径就是让官漏读一半。**
项目侧还没有那份文件时（新项目 / 休眠仓），首行只写通用那份，并在派单令里说明
「本仓尚无项目特有条款库」—— 别因为缺一份就整句不写。

**为什么这句要固定写、不许现场判断该不该带**（实测数据，不是设计偏好）：同属通用节、同一文件、
同样措辞强度的条款，携带率分裂成 **100% vs 9%** —— 跟着模板走的那条 68/68 全带，而要求帅
**每次重新判断该带哪几条**的两条只有 23.5% 与 8.8%。**区分变量不是文字 vs 机器闸，
是「形态」vs「判断」**。这一行同时解掉投递延迟：always-on 快照按 compaction 刷新
（实测约 12 小时），帅从自己快照里粘贴条款粘的是旧版；让官**自己 Read 盘上文件**，
读到的永远是最新版。

**仍需手工携带的唯一场景**：某条款是本轮刚写入盘上、而任务**强依赖**它 ⇒ 除首行外再把该条原文
粘进 prompt（双保险）。其余情况不要手工摘条 —— 摘条本身就是那个 9% 的病灶。

**⚠️ 这条首行目前是唯一真的在投递官侧条款的通道**：`ccswitch/hooks/dao-subagent-clauses.js`
那条自动注入通道虽已存在，但 `ccswitch/clause-index.json` 的源清单里**还没有**官侧档
（源清单住 `ccswitch/lib/clause-parser.mjs`）⇒ 它今天渲染不出官种节，只能给指针。
**别把「有个 hook 在管」读成「不写首行也没事」。**

  - **近似判据类批加一问「语料从哪来」**（本门的附加必填项）：改动涉及正则/启发式/关键词表等**近似手段**时，派单令须指定**外部语料来源**（真实命令历史 / 线上日志 / 竞品规则库 / 历史事故样本），**禁止「用本轮发现的形态构造正控与负控」**——内生语料只能证明「上一轮那些洞已补」，证不了「还有没有第 N+1 类」，结构上必然产出补漏—再漏循环。同批附一个可机械检出的停手信号：**同一文件 24h 内第 3 次返工即转设计评审**（`git log --since=24h -- <file>`）——反复补正则说明底座选错了，不是补得不够细（出处：叙事 N9-④）。 [n=11 @07-27 触发:派单契约门] [基线:某护栏正则被 11 个 PR 触碰、其中 8 个集中在 19.8 小时内，每层修复面 100% 落在上一层刚写的行上（共享比例 0.92–1.00）] [#派-语料来源]
  - **工具面门（派单前最后一眼）**：派之前把任务要求的动作逐条对一遍**那个 agent type 的 tools 列表**——凡出现「独立复跑」「mutation 换靶」「字节级复原」「真机截图」「起服务」，就都需要 Bash / Edit，**只读型 type（`Read/Grep/Glob`）结构上做不到**。判据一句话：**这个官被要求做的事，它手上有那个工具吗**。危险不在会失败，在于**它一路跑到最后才失败**——「没跑的闸」与「过了的闸」在台账上长得一样（零检出/零存在那个病的编排层版本；经过见 rationales §帅-3）。附带一条正向做法：重派时把上一轮的静态结论当**靶单**交给新官（只读官读码往往读得比能跑的官细），要求逐条打实或打掉，不许直接采信。 [n=2 @07-28 触发:派单契约门] [基线:本窗两次派对抗验证官皆选了只读 type（`dao-reviewer-critical`），三个定义性动作 3/3 落空] [#派-工具面门]
  - **派实验/真机类官时，派单令必须写明「写入面归谁」**：**射程判据（立后第一次应用就发现原文太宽，当日收窄）**：不是所有测量都要这一行——「某段时间内有没有发生 X」（reload 实验 / A-B 对照 / 偶发复现）**必须写**；「此刻这个值是多少」（读一个瞬时状态、拍一张截图）**不必写**。判据一句话：**我的结论依赖「这段时间只有我在动」吗**。⇒ 命中的任务，派单令须有一行说清**这段时间谁能往这个仓写、谁不能**。理由不是礼貌，是**实验前提**（为什么帅的写入会制造假阳性：见 rationales §帅-4）。判据一句话：**这一段时间里，仓里的每一次写入，我说得出是谁干的吗**。挂在派单令上而不是靠事后想起。 [n=1 @07-29 触发:派单契约门] [自定@07-29] [基线:本窗 1/1 次派测量类官即污染，且是帅自己；此前无同类条款] [#派-写入面]

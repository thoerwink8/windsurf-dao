# Phase 4 · 暗色模式改造（Dark Mode Transformation）

> 万物负阴而抱阳，冲气以为和。阴阳不是对立，是互补。

### 4.1 暗色模式的核心挑战

暗色模式不是"反转颜色"——是重新映射语义色到暗色背景下仍然可读、可辨、美观的值。

**三大陷阱**：

| 陷阱 | 现象 | 根因 |
|------|------|------|
| **死黑背景** | 页面像洞穴，眼睛疲劳 | `--background` 用了纯黑 `0 0% 0%` |
| **过饱和表面** | 彩色表面刺眼 | `--success-surface` 饱和度 >30% |
| **隐身文字** | 标签/状态文字看不见 | 暗色下 foreground 变量明度不够 |

### 4.2 暗色 Token 映射规则

**背景色策略**（温暖炭灰优于死黑）：

```css
.dark {
  /* ✓ 温暖炭灰（带色相的深灰） */
  --background: 220 18% 13%;      /* 有温度感 */
  
  /* ✗ 纯黑（避免） */
  --background: 0 0% 0%;          /* 洞穴感 */
  
  /* ✗ 纯无色相灰（避免） */
  --background: 0 0% 13%;         /* 冰冷感 */
}
```

**语义色映射四步法**：

| 步骤 | 亮色 → 暗色 | 调整方向 | 示例 |
|------|------------|---------|------|
| 1. 主色/强调色 | H 不变，L 提高 5-10% | 暗背景需更亮的强调色 | `222 100% 60%` → `222 100% 65%` |
| 2. 状态色（text） | H 不变，S 适度，L 提高到 55-65% | 保证文字可读性 | `0 84% 60%` → `0 70% 58%` |
| 3. 表面色（surface） | H 不变，**S 大幅降低到 12-16%**，L 降到 15-16% | 表面不能抢注意力 | `142 43% 94%` → `151 14% 15%` |
| 4. 边框色 | 透明度降低（从 0.42 到 0.22） | 暗色下边框更微妙 | `success/0.42` → `success/0.22` |

**关键公式**（经验值）：

```
暗色表面饱和度 = 亮色表面饱和度 × 0.3 ~ 0.4
暗色表面明度 = 15% ± 1%（几乎统一）
暗色文字明度 = max(55%, 亮色文字明度 - 10%)
暗色边框透明度 = 亮色边框透明度 × 0.5
```

### 4.3 暗色模式实施步骤

```
1. 先改 CSS 变量值（:root → .dark 映射）
   - 背景系：background, card, popover, workspace, surface-*
   - 前景系：foreground, muted-foreground, card-foreground
   - 状态系：success/warning/danger 的三要素（text, surface, border）
   - 控件系：border, input, control, control-hover

2. 截图验证（亮暗双模式）
   - 主页面截图对比
   - 重点检查：状态标签文字可读性、表面色是否过饱和、边框是否可见

3. 修复发现的问题
   - 优先改 CSS 变量值（一处改全局）
   - 其次用 .dark 选择器添加暗色专属覆盖
   - 最后才在组件上加 dark: 前缀

4. 再次截图验证 → 循环直到无可见问题
```

### 4.4 暗色专属 CSS 覆盖

有时 CSS 变量不够灵活，需要 `.dark` 选择器覆盖：

```css
/* 语义边框在暗色下需要不同透明度 */
.semantic-decision {
  border-color: hsl(var(--success) / 0.42);
}
.dark .semantic-decision {
  border-color: hsl(var(--success) / 0.22);
}
```

**原则：能改 CSS 变量解决的不用 .dark 覆盖；必须覆盖时写在 index.css 的 utilities 层。**

### 4.5 暗色模式检查清单

```
□ 每个 :root token 在 .dark 中有对应值
□ 背景色不是纯黑（明度 10-15%，饱和度 15-20%）
□ 表面色饱和度 ≤ 16%
□ 状态文字（success/warning/danger）在暗背景上清晰可读
□ destructive/danger 文字明度 ≥ 55%
□ 边框在暗色下可见但不抢眼
□ 阴影在暗色下仍然有层次感（或用 border 替代）
□ 输入框/表单控件边框可辨
□ 焦点环在暗色下可见
□ 概览页指标数字可读
```

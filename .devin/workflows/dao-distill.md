# 知识沉淀 · Distill

> 致虚极，守静笃。万物并作，吾以观复。

## 触发条件

- 用户显式调用 `/distill`
- 用户想综合本会话多轮任务的教训，统一写入文档

> **注**：单次任务的教训提炼已内置于 `/cycle` 涅槃流程。`/distill` 用于**会话级全量扫描**。跨会话的 Git 考古已并入 `/evolve`。

## 流程

### 一、识（☲视·扫描当前会话）

回顾**本会话从头到尾的全部内容**，识别所有可复用的洞察：

- 踩坑经验：做了无效尝试、发现外部系统行为与预期不符、推翻假设
- 新模式/反模式：发现了更优做法，或确认了某种做法不可行
- 架构/设计决策及理由
- 工具/库/API 的正确用法（与文档/预期不一致的部分尤其重要）

### 二、去重（☶艮·先查再写）

用 `search.py lessons "关键词"` 搜索已有教训，统一去重：

- 已有记录 → 跳过
- 新洞察 → 进入写入
- 与已有冲突 → 替换旧内容并注明

### 三、写（☳触·直接写入）

用户触发 `/distill` 即是授权，不需 `ask_user_question` 确认。按 `knowledge-routing.md` 路由表写入对应文件。教训写入加载 `dao-evolution` skill。

### 四、虚（☴巽·清理残留）

> 万物归根，归根曰静。

扫描存活 Memory → 归位到文件 → 删除。**Memory 一旦写入文件即应清理。**

## 反模式

- **为沉淀而沉淀**：纯执行性任务无需沉淀
- **重复写入**：写入前必查已有内容
- **Memory 堆积**：写入文件后忘清 Memory
- **过度细碎**：合并同类，保持精炼

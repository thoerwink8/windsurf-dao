# 盲设计题

## 何时用

三入口，任一即可：

1. 用户说「出设计题」。
2. 重大设计岔路的 AskUserQuestion 选项里选了「先出盲设计题」。
3. 体系类 PR 模板的设计阶段栏需要盲设计题 diff。

适用：解空间宽的重大设计题——体系类改动、新组件形态、架构拓扑。

不适用：「A 还是 B」已经收敛的选择题。那种直接问。

## 题面模板

只写这四块，一块都不能少，一块都不要加戏：

- 背景
- 用户诉求
- 你要回答的
- 「不要读仓库现有约定文件，仅基于题面独立思考」

一字不得提示期望的方案形态。题面里出现「用配置文件」「别写进散文」这类暗示，这轮作废。

## 盲纪律

- ≥2 个不同厂商的模型。同厂商对照臂可以加，但不能算作「两个盲臂」。
- 臂起在中性目录，不在仓内。CLAUDE.md / AGENTS.md 会自己注入——嘱咐拦不住会先侦察再干活的 CLI，环境隔离才拦得住。
- 开跑前预注册判定标准。跑完再定「什么算命中」，等于没考。
- 容忍单臂阵亡：限流、破盲都记档，不重跑。≥2 臂就是为了扛这个。

## 收卷

各臂方案做 diff。分歧点整理成 AskUserQuestion 选项交用户拍板；一致点直接采纳。

## 判例

issue #438：2026-08-14 三臂实验，两守盲臂独立命中「结构化配置文件」。这是本机制的出生证明。

# 拍板说白话

## 何时触发

用户要拍板、给消歧选项，或说「没看懂」「说白话」，或手动挂本 skill。

## 硬规矩

AskUserQuestion / 岔路选项的**标题**里，不许出现用户没说过的词。内部名可以放在题干括号里一次，不进选项标签。

当场拍板若有推荐项，在选项标签**末尾**加「（推荐）」（必须这四个字，不要改写成别的）。最多标一个。不推荐仍可选；推荐不是代选。选项标题仍须白话。

用户说「没看懂」：立刻用白话重问同一件事。不要解释为什么难，不要加新 skill。

## 判例（2026-08-22）

- #489 第一轮「结构化声明 / coordinator loop」听不懂 → 改成「敏感文件有没有事先声明，写在哪」才选了 PR 勾选框。
- #530 第一轮「流转器 / coordinator loop」听不懂 → 改成「工人干完谁交给审官」后，用户定为同一对工人审官 N 轮乒乓、不新开工人。

## 边界

不替代消歧门：仍要岔路/结论/依据；本页只管**问法**。不要写成长篇，不要造脚本。

规则补丁累积是反道。发现问题 → 加 🔒 铁律段是症状治标；加验证闭环（自动检测偏差）才是根因治本。

**Why:** 实战中连续三次发现 UI 问题（字号/体系裂痕），每次都加一条铁律段到 skill，结果 skill 膨胀但问题源头（实施后不验证）没堵住。用户质疑"为什么第一次就没解决"点出本质：开环流程靠补丁堵不住。

**How to apply:** 当发现自己要往 dao.md 或 skill 加"禁止 X"/"必须 Y"补丁时，先问：能不能加一个自动验证步骤来捕获这类偏差？能 → 加验证，不加补丁。为道日损：每多一份验证自动捕获，可少一份补丁铁律段。

# 不可协商层（C1..C7）

> 这一层**刻意保持少**（当前 7 条，上限也是 7 条）。加一条的代价 = 所有子仓都要动一次，
> 所以**进这层要举证**：不加会出什么事、能不能靠默认继承层解决。超上限由 `stamp.mjs --check` 判红。
>
> 子仓怎么接：`kit/check-conventions.mjs` 校验子仓里那条约定块（版本 + sha256）与它的 pin 对得上；
> 豁免写在子仓的 `## 豁免` 段，**每条必须带理由**。

## C1 三态输出：「没查成」不是绿

每个检查只许有绿 / 红 / **没查成**三种结论；取不到、读不成、没样本一律落「没查成」，
**不许折算成绿**。「扫完查出 0 条」与「这次没扫到任何样本」必须分得开。

## C2 抑制必须带理由

关掉一条检查只许用带理由的形式（`dao-check-ignore: <规则> -- <理由>` / `DAO-DEBT:<指纹>` / `## 豁免` 段），
**裸抑制一律红**。理由要写「为什么这条不适用」，不是「先关掉」。

## C3 凭据不进聊天与仓库

token / cookie / 私钥不进对话、不进 git、不进日志。要用就放家目录的凭据目录，由载体去读。

## C4 issue 写动作走网关

`create|comment|close|edit` 只走本仓的 issue 网关（身份由它固定），**不许裸 `gh issue` 写**、不许自选 token。
读不限。

## C5 家目录落点先查清单

往家目录（`~/.<工具>/…`）写东西之前先查落点清单：归本仓的才在本仓写装法，
归他仓的只留指针、不在本仓复制装法。

## C6 新检查上线前先构造故意违规样本

「已安装」不是证据，「故意违规被当场拦下」才是。没有违规样本的检查视为未上线。

## C7 闸只拦确定性的量

闸拦的东西必须两次跑得出同一个结论（如 spawn 数、条数、存在性）。
墙钟耗时、随机采样这类在有负载的机器上会漂的量**只报趋势，不当闸**——随机误报的闸最后一定被关掉。

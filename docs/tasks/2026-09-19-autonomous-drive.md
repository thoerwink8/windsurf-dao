## 每轮做什么

1. **读清盘面**：主树 `git pull` → 读 #1460 的任务表 + 最近几条 `[进度]`/`[断链]` 评论 → 确认基建队列头是谁。
   （#1460 是主清单；#816 是伞单，只装里程碑与指针。）
2. **起树**：`git worktree add -b devin/<短名> <路径> origin/master`。**一件事 = 一个 PR**，不并多件。
3. **做完就验**：单测 → `node scripts/dao-check.mjs`（**零新增红**才算；红了当场处理或如实报告）→
   再真跑一次 E2E 拿证据（能真跑就别只交单测）。
4. **交卷**：commit 前缀 `[devin]`，标题写 `feat(T..): …（#单号）` → push →
   `node scripts/dao.mjs pr-open --model devin-acp-deepseek --reviewer codex-relay-gpt-5.6-luna --issue <号>`
   → `gh-as marshal -- pr ready` → CI 绿 → `gh-as marshal -- pr merge --squash --delete-branch`。
5. **留痕**：一行 `[进度]` 到 #1460（带 PR 号 / commit / 证据指针）+ 对应 T 单一条状态评论。
6. **断链当场记**：`[断链]` 一行到 #1460（现场、后果、处置），**并开单修复**——
   同一 slug 只许一张 OPEN 单，先查起因有没有已有单在管。

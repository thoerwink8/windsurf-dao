# 机制巡检：#1164 让 ⑳ 拼 drop-in 之后，本机两份故意的本机配置把闸钉成永红

## 结论

#1164 修的是「只读正文看不见 drop-in」。修法是把 `/etc/.../<名>.d/*.conf` 拼进有效单元再跟仓内文件比，不一样就红。skills-heal 这台机器上已经装上，⑳ 剩下的 3 个漂移全是**故意留在机器上的东西**：飞书群映射 drop-in、mirasim 升级器 drop-in、gw-remote-probe 差一句注释。仓内 `mirasim-server.service` 自己写着升级器那份 drop-in「不是本仓的，装机脚本不准删」——他们知道 drop-in 会让 ⑳ 漂，所以把 memory-guard 合进正文，却把这份升级器 drop-in 留在闸的扫描面里。⑳ 要拦的「改了仓没装机器」和「本机故意的配置」从此分不开。测试还把「正文对、drop-in 改日历」锁成必须红，没有「这份 drop-in 算在役」的分支。

### 2. 三个漂移各自是什么

**feishu-triage**：仓内正文与 `/etc` 正文 `diff` 空。活 drop-in `/etc/systemd/system/feishu-triage.service.d/10-local.conf`（mtime 2026-09-06 00:54）原文：

```

# 实机映射放 ~/.mirasim/keys/feishu-groups.json（600，与 feishu-app.json 同目录，换机一起手动带）。
[Service]
ExecStart=
ExecStart=/usr/bin/node /srv/projects/windsurf-dao/scripts/feishu-triage.mjs --groups /home/orca/.mirasim/keys/feishu-groups.json
```

仓内 `host/machine/systemd/feishu-triage.service:49` 是不带 `--groups` 的那一行。`assembleEffectiveUnit` 把 drop-in 拼进去，跟仓内正文一比就红。这是审官要求的本机配置，不是忘了装。

**mirasim-server**：仓内 `host/machine/systemd/mirasim-server.service:18-19` 原文：

```
# 升级器自己的 managed-update.conf（改 ExecStart 走 run-server.sh）不是本仓的，
# 装机脚本不准删。
```

同文件 16–17 行写过：memory-guard 合进正文「以免 ⑳ 只比对 .service、drop-in 继续漂」。活 drop-in `/etc/systemd/system/mirasim-server.service.d/managed-update.conf`：

```
[Service]
WorkingDirectory=/home/orca/mirasim-server/current
ExecStart=
ExecStart=/usr/local/lib/mirasim-managed-update/run-server.sh
```

`systemctl show mirasim-server.service -p ExecStart` 就是这一条。仓内正文 `ExecStart` 仍是 `.../current/node .../current/server.cjs`。这份差是升级器的在役形态，注释禁止删。

**gw-remote-probe**：`diff` 只有注释少了「但仍不许读个人 gh 登录」半句。活 `ExecStart` 已经是仓内 `scripts/gw-remote-probe.mjs`（09-08 那条「还在跑 ~/bin」已处置，不另报）。没有 drop-in。⑳ 对注释也红。

`scripts/server-check.mjs:917-926` `assembleEffectiveUnit` 追加每个 `.conf`；`:994` `norm(repo) !== norm(live)` 就进 drifted。0 处白名单、0 处「drop-in 算在役」。同文件 1437–1447 行自测把「正文对但 drop-in 改日历」锁成必须红。

## 建议的最小改造

删掉「有效单元全文必须等于仓内文件」这一层。⑳ 问的应是「该装的装了没有、ExecStart/User/日历这些契约字段对不对」。本机故意的 drop-in（飞书群映射、升级器）不进漂移；注释差一句不进漂移。不要再给闸加一份「允许的 drop-in 名单」——#1164 刚把 drop-in 拼进来，再加名单是第二层，第一层还在把在役配置当故障。

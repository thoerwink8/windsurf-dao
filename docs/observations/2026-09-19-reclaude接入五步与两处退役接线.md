# reclaude 接入：五步 + 两处必清的退役接线（2026-09-19）

用户报「本机 mirasim 的 reclaude 会话 401 / Not logged in」。逐层排除后定位到**顺序 + 缓存**，不是链路本身。

## 真凶

mirasim 起 agent 时传 **`{...process.env}`——它自己进程的 env**（`server.cjs`：`spawn(cmd,args,{env:{...process.env,'CLAUDE_CONFIG_DIR':…}})`）。
桌面端 **16:18 启动**，而 reclaude 的代理/CA 接线 **23:03 才写进 `~/.claude/settings.json`**。
⇒ mirasim 一直拿 16:18 那份旧 env 起 claude（没 `HTTPS_PROXY`、CA 指旧网关）⇒ claude 到不了 reclaude ⇒ **Not logged in**。

**重启 mirasim 桌面端**即通。命令行直接起的复现全通，是因为 shell 每次现读 settings.json——**这就是「我复现不出来、用户却必现」的原因**。

## 正确顺序（缺一步就 401）

1. **装 + 登录 reclaude**（`reclaude login`，浏览器设备授权）。
2. **`~/.reclaude/claude.path` 写绝对路径** → 确定性指定跑哪份 claude。
   不写它，reclaude 自己解析——实测两端会解析到**不同的二进制**（root 走自带那份、orca 走原生那份）。
   地板 **≥ 2.1.277**（Claude Code 从这版起才在「没有 CLAUDE.md 时回退读 AGENTS.md」）。
3. **`~/.claude/settings.json` 要有 reclaude 接线**：`HTTPS_PROXY` → reclaude daemon 端口、
   `NODE_EXTRA_CA_CERTS` → `~/.reclaude/ca.pem`、`NO_PROXY`。reclaude 首次真跑 claude 时会补写。
4. **清掉退役接线**（见下）。
5. **改完 env / settings.json 必须重启 mirasim 桌面端**（进程 env 缓存）。
6. 最后才写 `agentLaunch.claude.command = "reclaude"`（**先授权后写键**：反了每个会话都跑未登录的 reclaude，启动即死而卡面显示 running）。

## 两处必清的退役接线（本次实咬）

| 落点 | 症状 | 清法 |
|---|---|---|
| `~/.config/ai-gateway/claude-env.sh` 的 `ANTHROPIC_*` | 指退役 HK new-api 网关 + 旧模型别名 ⇒ `[claude-code:unrecognized_model] claude-5-fable-medium` | 去掉那四行（保留无害开关）。**注意 `su` 看不见、只有 `su -`（登录 shell）才带上** |
| 用户级 `NODE_EXTRA_CA_CERTS` 指旧网关 CA | 该变量**只能指一个文件**；指了旧网关 CA，reclaude 的 CA 就不在里面 | 改指 `~/.reclaude/ca.pem`（改完同样要重启 mirasim） |

## 别走的弯路（实测排除过）

- 手动替换 reclaude 自带那份 CLI → 会被 `dl.reclaude.ai/claude-cli/latest` 比对**强制重下覆盖**。
- 改 metadata 版本号骗过它 → 能过，但**是对上游谎报版本**，别用。
- `agentLaunch.claude.command` 改成裸 `claude` → 丢代理/凭据/CA 整条链。
- `--settings '{"env":{}}'` / `CI=''` / `TERM=dumb` / `--output-format stream-json` / `--resume` → 逐个复现**都通**，都不是原因。

## 落点归属（未来别的机器复用照这个分派）

- **装法 + 机械检查 → `ai-gateway-stack`**（`~/.reclaude` / `~/.mirasim` / `~/.config/ai-gateway` / `NODE_EXTRA_CA_CERTS` 都是 E 类）。闸：`deploy/machine-check.mjs` 的 `checkReclaudeEnv`（退役 env + 版本地板），**待补 `NODE_EXTRA_CA_CERTS` 一格**。
- **判例 + E 类登记 → 本仓**（`host/machine/INDEX.md` 补 `~/.reclaude`）。

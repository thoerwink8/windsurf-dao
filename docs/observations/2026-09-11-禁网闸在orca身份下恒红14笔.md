# 禁网闸 14 笔恒红：identity 相关，baseline 上同样出现

## 结论

`dao check` 的禁网闸（`tests/helpers/no-network.mjs`）在 **orca 身份**下每次报
「测试期有 14 次外网连接尝试」，全部指向 `api.github.com:443`、`via=net.connect`、
`argv` 为空。在 **root 身份**下同一份代码 0 笔。

这直接堵住 `land.mjs`：它推之前跑 dao-check，红了就不推（`master 必须能跑`），
而 `dao-land.service` 是 `User=orca`。2026-09-11 22:19 那轮 timer 落地的就是
「1 项红 / 236 项绿」，那 1 项就是本闸 —— 所有提交从此推不上去。

## 已排除的

- **不是本轮改动引入的**：`origin/master`（未含本轮任何提交）连测两次，同样 14 笔。
- **不是某个测试套件**：177 个 `tests/*.test.js` 逐个跑（含 `--import` 预加载）、
  按 89/88 对半并行跑、按 15 个一批并行跑，**全部 0 笔**。
- **不是 `--full` 档或 server-check**：`dao-check --full` 与 `server-check.mjs`
  在预加载下都是 0 笔。
- **不是 gh / gh-as 直接调用**：`gh` 是 Go 二进制，`--import` 只对 node 生效，
  它连不上预加载；`gh-as.test.js` 单独跑 0 笔。

## 已知事实（供后来者接着查）

- 清空账本目录后用默认路径跑一次：**14 笔，且只生成 1 个新账本文件** ⇒ 确实是这一轮
  跑出来的，不是继承旧账。
- 但同一轮里，测试阶段（每套件单独 spawn、只差一个 `DAO_NO_NETWORK_LOG` 指向别处）
  是 0 笔。改用独立路径跑全量 → 0 笔；用默认路径 → 14 笔。
- 14 笔的间隔 0.26s–26.6s 不等，`ppid` 每次不同 ⇒ 14 个各自短命的 node 进程。
- 差异只有身份：**orca 家目录有 GitHub 凭据（`~/.dao/apps/marshal.pem` 等），
  root 没有**。`scripts/lib/gh.mjs` 的 `mintInstallationToken` / `listInstallationRepos`
  两处 `fetch('https://api.github.com/...')` 是仓内唯一会打这个域名的代码。

## 下一步（未做）

最可能的路径：某个 mock 没把 `fetchImpl` 注进去，落到真 `fetch`；root 因为没有工单
凭据而提前 `creds_missing` 返回，所以看不出红。抓手：
`grep -rn "mintInstallationToken\|resolveToken\|listInstallationRepos" tests/`，
逐个确认 `fetchImpl` 有没有注。

**在查清之前，land 推不动**——这本身比这条观察更急。

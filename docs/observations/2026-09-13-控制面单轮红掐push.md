# 机制巡检：ws-probe 单轮握手红立刻把控制面写成 reachable=false，全机 git push 停到下一轮；自愈要连红 2 次，探针 exit 0

## 结论

`control-plane-write.mjs:13` 自己写着「不许把没查成写成 false——一次抖动会锁死整条链」。没查成那一档确实不写 `reachable`。握手「连不上回环 ws」却被收成 **red**，同一轮就落盘 `reachable=false`。git pre-push / land 见 false 就拦。自愈要连红 2 次才 `try-restart`，默认探针还 `exit 0`，systemd 绿。

本轮就是一次抖动：00:28 探活红、控制面 false，巡检 rebase 完第一次 `git push` 被掐；00:38 探活绿、控制面 true，第二次 push 上去。中间这 10 分钟里，起这次巡检的 mirasim-server 一直 `active (running)`，本会话从 00:24 活到现在。闸按设计在拦，拦的是必须 `git push` 的巡检，没有第二条写腿。

### 2. 单轮红立刻写 false；自愈要 2 次；单元恒 0

`scripts/lib/control-plane-write.mjs:9-13`：

```
//   green     → {reachable:true}
//   red       → {reachable:false, error}
//   unscanned → 不写 reachable（探头读成没查成，不拦）
// 不许把没查成写成 false——一次抖动会锁死整条链。
```

`:42-45`：`state === 'red'` → `{ reachable: false, … error }`。

`scripts/lib/mirasim-ws-probe.mjs:42-44`：消息匹配 `连不上回环 ws` → `{ state: 'red' }`，不是 unscanned。
`:90`：红才 `strikes+1`，绿立刻清零。
`:19`：`DEFAULT_STRIKES_TO_HEAL = 2`。
`:115-116`：green / unscanned 都不动刀。

`scripts/mirasim-ws-probe.mjs:191`：`process.exit(STRICT && red ? 1 : 0)`。timer 不带 `--strict`。
`host/machine/systemd/mirasim-ws-probe.service:41-42` 注释：「退出码 0 = 探过（红项走报警 + 自愈，不算探针失败）。」

本轮 00:28 与 00:38 两次 `ExecMainStatus=0`。`--failed` 没有这个单元。00:28 那次 red 的 strikes 被 00:38 绿清成 0，自愈从未触发（`healed=false`）。

## 建议的最小改造

删掉「单轮握手红 → 立刻 `reachable=false`」这一层。控制面落点跟自愈用同一把滞回：连红 2 次再写 false，单轮红当没查成（不写 reachable，闸不拦）。`control-plane-write.mjs:13` 那句对抖动的判断，现在只罩住了 unscanned，没罩住会被收成 red 的「连不上」。

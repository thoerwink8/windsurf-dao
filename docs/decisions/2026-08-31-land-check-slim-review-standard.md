## 二、dao-check 评估结论：架构留，节奏门

**对比市面**（分层门：本地快门 + CI 全量 + 运行时监控；制度即代码类工具 danger/conftest/ArchUnit）：
dao-check 的四条铁律（0/1 退出、扫描不清单、没查成≠绿、夹具验判别力）**高于**市面常规水平，不换。
真问题两个：
1. **提交门里混着网络/外部活探**（gh 盘面 ×3、orca ×2）——慢、抖、CI/新机常年 SKIP；
2. **检查只进不出**：27 项里大半守的是已冻结的派工机器（dbfa323 守卫归零），每次提交仍全款付费。

**改法（本 commit）**：加停派工态门——⑦ orca --help、⑭ open 单阈值、⑮ 可立即起、⑰ 账本断流 live
四项默认不跑，输出「停派工态未跑（--full 跑全量）」第三形（≠绿 ≠没查成）；`--full` 跑全量，
服务器编排回岗后把 --full 设为常态。离线的夹具/接线检查全保留（不花网络，守的约定还在仓里）。
**不做**：按「冻结清单」拆测试套——手写清单违反铁律 2，且冻结代码的整体退役随服务器搬家一起做
（8-24 保留/删除清单已排：⑦⑧⑨⑳ 要改要删，①③⑤㉖ 平台无关留下）。

## 三、land 收工命令（体系类三问）

1. **谁提的**：用户 2026-08-31——任何装了 windsurf-dao 的机器，commit 后自动推主分支、删 worktree
   和派生分支，本机与 Linux 复用同一逻辑。
2. **删哪层**：删「人记得收尾」这层。承重面是一条幂等命令（`scripts/land.mjs`）+ 全局约定一行
   触发（commit 完跑它），不是常驻进程、不是 git hook。
3. **从零重做还造吗**：造——8-24 的判据「留下的必须是一条能跑的命令，不许是一段要记住的纪律」。

**用户三问的判定**：
- **与 orca 编排冲突吗？** 有两处真隐患，都在决策层挡死：①自动把派生分支运进主分支 = 绕过审官
  ——land 只运默认分支，派生分支直接拒绝（进主分支走 PR/审官闭环）；②自动删树可能砍掉在跑的
  agent（deleted-card 判例）——只拆「已合并+树干净+非主树/非当前/不挂默认分支+orca 没在管」的树。
- **与 dao-commit 冲突吗？** 不冲突且互补：dao-commit 管怎么写 commit（前缀/版本号），land 管写完
  怎么运走；land 推前跑 dao-check（含版本号载体闸 ㉗），反而把 dao-commit 的约定变成推送前置。
- **为什么不做成 post-commit hook（真·每次 commit 自动）？** rebase/amend/cherry-pick 都会触发
  post-commit，中间态会被推上主分支；编排树里工人的 commit 也触发，等于绕过审查。「收工」的
  正确粒度是一段活的结尾，触发放在全局约定行（AI 每次 commit 完就跑，用户无感）。
- **本地/Linux 复用**：同一条命令。服务器上由 automations 在合并后调它做清理，工人永远不调。

安全判断全在 `scripts/lib/land-core.mjs` 纯函数层，`tests/land.test.js` 含真 git 临时仓 e2e：
该删的删了、脏树/未合并支/orca 树一根毛没动（每道闸有故意样本）。

## 四、选型四源审计（结合 ai-gateway-stack；只记结论，Phase 1 才动手）

现状四个载体描述模型：`model-routing.json`（职责/顺位/禁令）、`model-routing.toml`（launch 模板）、
`policy/models.yml`（点将台 registry+价目，fx 自 8-22 待补）、**网关 new-api 降级池**（别名+priority，
故障注入实证过）。重叠点：JSON 的 厂商/pipes 层 + `next-launch` 的换支路逻辑，与网关池的
「同名模型换渠道」是**同一件事的两个生产者**（two-producers-one-resource）。

**Phase 1（服务器编排回岗时）的收拢方向**：
1. 渠道级降级唯一归网关（模型 id = 网关统一别名；删 pipes 层与 `-direct` 类手术，next-launch 只剩
   「换模型」不再「换支路」）；仓内 JSON 只留**职责层**（谁干什么工种、顺位、禁令、审官换厂）。
2. `models.yml` 价目层挂起不再手抄（LLM 价格不许凭记忆判；网关有真实用量账）——点将台回岗时
   改从网关用量/账单取数，fx 待补的摊销字段一并处理。
3. 现在不动：派工冻结中，改了没有消费者验证（migration-half-done 教训——检查面与真相源要同 PR 换）。

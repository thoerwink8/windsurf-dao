# 帛书老子全文（德道二经合）

本文为帛书甲本《老子》原文，按德经（上篇）、道经（下篇）顺序排列，共 81 章。与传世本"道可道，非常道"不同，帛书作"道，可道也，非恒道也"。

完整经文存于 `@references/帛书老子.md`，当前为指针式引用。需全文时，请读取该文件。

**德经精要**（部分章节）：

- 三十八章：上德不德，是以有德；下德不失德，是以无德。上德无为，而无以为也。
- 四十八章：为学者日益，闻道者日损。损之又损，以至于无为，无为而无不为。
- 六十三章：为无为，事无事，味无味。大小，多少。报怨以德，图难于其易也，为大于其细也。
- 六十四章：其安也，易持也；其未兆也，易谋也。为之于其未有也，治之于其未乱也。慎终若始，则无败事矣。

**道经精要**（部分章节）：

- 一章：道，可道也，非恒道也。名，可名也，非恒名也。无名，万物之始也。有名，万物之母也。
- 八章：上善如水。水善，利万物而有静，居众之所恶，故几于道矣。
- 十一章：卅辐同一毂，当其无有，车之用也。故有之以为利，无之以为用。
- 二十五章：有物昆成，先天地生。吾未知其名，字之曰道，强为之名曰大。道法自然。
- 四十章：反也者，道之动也；弱也者，道之用也。天下之物生于有，有生于无。
- 四十二章：道生一，一生二，二生三，三生万物。万物负阴而抱阳，中气以为和。

# 道藏阴符经全文

《黄帝阴符经》，道家经典，分天发杀机、人发杀机、天人合发三章。

完整经文存于 `@references/阴符经.md`，当前为指针式引用。需全文时，请读取该文件。

**精要摘录**：

- 神仙抱一演道章上：观天之道，执天之行，尽矣。天有五贼，见之者昌。
- 富国安民演法章中：天地，万物之盗；万物，人之盗；人，万物之盗。三盗既宜，三才既安。
- 强兵战勝演术章下：瞽者善听，聋者善视。绝利一源，用师十倍。自然之道静，故天地万物生。

# 形 · HTML 形态探索

> 无状之状,无物之象,是谓惚恍。大象无形,转其形而显之。——《道德经》

让无形的设计语言显形,让用户**看见**之后再决策。AI 描述的"暖米白 + 深墨蓝"再生动,不如让用户在浏览器里直接看见、点得动。

## 定位:HTML 是思考脚手架,不是真相源

> 这是本 skill 的范式根基,先读懂再用。

**HTML 原型的唯一使命:消除"形态/交互的未知"。** 它回答的是"这个东西该长什么样、怎么交互",不是"代码要 1:1 还原它"。

```
HTML 原型 = 一次性思考脚手架(throwaway thinking scaffold)
  ├─ 使命:帮用户/AI 想清楚形态与交互
  ├─ 完成即归档,放 _tmp/ 或 docs/design/_archive/
  ├─ 绝不为它写契约/像素测试
  └─ 真相在代码,不在 HTML

唯一长期产物 = design tokens(色/字/间距/圆角)
  └─ 它才是被代码引用、长期维护的真相源(见 dao-design-assets)
```

**与旧范式的决裂**:不再"mockup 即 ground truth、代码对齐像素"。那是 push 模型,会逼出双向同步和像素契约。本 skill 现在是 reflect 模型下的**前期探索工具**——探完即弃,代码才是真相。

## 何时调用(由 dao-design-taste §0 分诊决定)

本 skill 不自行判断要不要启动,它由基石 `dao-design-taste` §0 分诊门派发:

| 分诊档 | 是否调用本 skill | 范围 |
|---|---|---|
| **FULL**(项目启动/换肤/大重构) | ✅ 调用 | 全量:完整组件库 + 多场景 |
| **SCOPED**(加一块形态未知的新东西) | ✅ 调用 | **只画这一块功能**,不重走全量 |
| **DIRECT**(已知形态里做事) | ❌ 跳过 | 直接查 gallery 写代码 |

**HARD-GATE**:FULL/SCOPED 档,用户未看过 HTML 并拍板形态前,不写实施 plan、不动样式代码。
**反向 HARD-GATE**:DIRECT 档,不要画 HTML——形态已知还画原型是浪费(违背为道日损)。

## 五步法(察 → 援 → 拟 → 显 → 择)

> 原六步法的第六步「固」拆出:像素验证(旧 6.2)已废除,tokens 导出并入「择」之后。

### 一、察(项目上下文分析)

> 知人者智。不读项目就生成原型 = 闭门造车。

扫描以下,产出**项目画像**(一段话:项目本质 + 目标用户 + 关键场景):

| 扫描项 | 看哪里 | 提取什么 |
|---|---|---|
| 产品定位 | README / AGENT 文档首段 | 一句话本质 + 目标用户 |
| 当前阶段 | TODO / specs | 已完成 / 进行中 / 将做的功能 |
| 技术栈 | 项目依赖清单 + 样式方案配置 | 框架、CSS 方案、组件库风格 |
| 现有视觉 | 主题文件 / 入口样式 | 当前 tokens、字体、布局 |
| 关键场景 | 主要组件目录 | 用户最常看到的 2-3 个界面 |
| 现状(可选) | 跑 dev server 截图 | 当前 UI 真实长相 |

**SCOPED 档简化**:只扫与"这一块新功能"相关的上下文,不全量扫。

### 二、援(借鉴已验证的视觉哲学)

> 善用人者为之下。借力已验证的设计系统,胜过凭空发明。

**配色/字体/风格方向不凭空发明,从供给源取候选给用户拍板。** 供给源优先级:

1. **ui-ux-pro-max(主供给源,若已注入)** — 按项目画像(产品类型/行业/关键词)检索其 styles/palettes/typography 库,取 3-5 套候选。这是配色/字体方向的首选来源(成套、含语义、可落 token)。
2. **用户提供的参考** — 用户点名的产品、贴的截图、链接的 URL。
3. **基石 §4 准则直接定** — 无供给源、无参考时,由 `dao-design-taste` §4 通用判据(禁 AI 紫、单一强调色、饱和度<80%、字体有性格)直接定一个克制方向,不强行外求。

> **依赖说明**:ui-ux-pro-max 是外部 kit(windsurf-skills-kit)提供的可选 skill,需经注入才可用(见 dao 部署文档)。未注入时跳过供给源 1,走 2/3,本 skill 仍可用——不悬空依赖、不假装它一定在。

**拍板模式(走 AskUserQuestion)**:给用户 3-5 个候选(附来源与一句话气质),用户选定或微调后进「拟」。

### 三、拟(设计方向拟定)

> 治之于未乱。方向先在脑里过一遍,再落到 HTML。

基于「援」拍板的方向 + 「察」的项目画像,合成 N 套设计方向。每套含结构化 tokens(色/字/间距/圆角/阴影/动效),结构见 `templates/design-tokens.schema.json`。

**多样性原则**(N≥2 时):方向间必须显著不同(明/暗、衬线/无衬线、密/疏 至少各一),给用户真选择,不是 3 个相似色相微调。

**受基石约束**:所有方向必须过 `dao-design-taste` §2 三旋钮定位 + §4 判据(禁 AI 紫等),不产出基石判据会打回的方向。

### 四、显(生成 HTML 思考脚手架)

> 大象无形,转其形而显之。让形态在浏览器里活过来。

读模板 `templates/mockup.html`,注入方向 tokens + 项目真实场景,生成单 HTML。

**输出**:`_tmp/ui-mockup-<topic>-<时间戳>.html`(临时区,throwaway)

**必含**:方向切换 + 暗色切换 + Foundations(色/字/间距/圆角)+ 关键组件 + 项目真实场景(SCOPED 档只含那一块功能的场景)。

**技术约束**:
- 单文件、零外部 CDN(离线可开)
- 真实文案 + 真实数据结构(不用 Lorem Ipsum)
- 可实现性自检:视觉效果必须能用项目现有 CSS 方案实现,不堆落地不出来的滤镜/3D

### 五、择(用户审视并选定 + 导出 tokens)

> 知止不殆。让用户在浏览器看完做决定。

打开 HTML 让用户审视形态与交互。**用户必须显式选定方向**(或"选 X + 微调 Y"),AI 不替选、不跳过。

选定后**只导出一个长期产物**:

```
_tmp/design-tokens-<topic>.json   ← 唯一长期真相(色/字/间距/圆角/阴影/动效)
```

可选附带 `index-css-draft`(CSS 变量草稿,方便落地)。**不再产 selector-mapping、不再产 component-deltas**(那些是旧像素验证的配套,已废)。

HTML 本身:选定后归档(移到 `docs/design/_archive/` 或留 `_tmp/`),**不维护、不写测试**。

## 验收(不做像素 diff)

> 旧 6.2「mockup-vs-impl 像素 diff」已彻底废除。它是把 HTML 当真相、逼代码对齐的契约残留,正是拖慢迭代的根。

实施代码后,验收交还给基石 `dao-design-taste` §6:

1. 过 §4 体检表(字体/禁 AI 紫/单一强调/阴影染色/交互状态全周期/对比度 a11y/文案自审)
2. preview 真实渲染肉眼看

**不再**跑 playwright 量 HTML 与代码的 computed style 差异,**不再**要求差异 ≤ 1px。HTML 是用过即弃的脚手架,拿它当验收基准是范式错误。代码长什么样,就是什么样。

## 双模式(可选)

| 模式 | 触发 | 产出 |
|---|---|---|
| **Style Tile** | "先看大方向" / 方向数 ≤ 2 / SCOPED 单功能 | 简化 HTML(Foundations + 1 场景) |
| **Style Guide** | "细化看组件库" / FULL 全量 | 完整 HTML(组件库 + 多场景) |

## 与其他 skill 的关系

```
dao-design-taste(基石)
  └─ §0 分诊 FULL/SCOPED → 调用本 skill;DIRECT → 跳过
  └─ §2 三旋钮 / §4 判据 → 约束「拟」的方向
  └─ §6 验收 → 接管实施后验收(本 skill 不再自带像素验证)

ui-ux-pro-max(外部 kit,可选注入)
  └─ 作「援」步的主配色/字体供给源;未注入则降级走用户参考 / 基石准则

dao-design-assets(资产落地)
  └─ 消费本 skill 导出的 tokens;HTML 不参与落地,代码即真相

dao-plan / dao-execute
  └─ 拿 design-tokens-<topic>.json 实现(不再拿 HTML 当 ground truth)
```

## 反原则

- **HTML 是脚手架不是真相** — 用完归档,绝不写测试、不逼代码 1:1 还原
- **DIRECT 不画原型** — 形态已知还画 = 浪费
- **不悬空依赖** — ui-ux-pro-max 未注入就走降级路径,不假装它在
- **唯一长期产物是 tokens** — 其余皆临时
- **不为流程而流程** — 已有明确 tokens / 方向时,跳过本 skill 直接落地

法不违德,德不违道,道法自然。

# Session Report · 会话自报

> 知人者智，自知者明。

## 约定

状态文件路径：`_tmp/sessions/<session-name>.md`

- `<session-name>` 由用户在运行时提供，或从当前任务推断（如 `account`、`firebase`、`ui` 等）
- 如果 `_tmp/sessions/` 不存在，先创建它

## 步骤

### 1. 感知本会话状态

读取以下信息：

- 当前工作目录的最近 git log（最近 10 条）：
  ```
  git log --oneline -10
  ```
- 当前 git diff（有无未提交变更）：
  ```
  git status --short
  ```
- 当前 TODO.md（如存在）
- 本会话对话中已完成的核心工作（从对话上下文中归纳）

### 2. 归纳状态

用以下结构归纳：

```
## 状态：[进行中 / 已完成 / 阻塞]
## 负责模块：[模块名]
## 已完成
- ...
## 进行中
- ...
## 阻塞/待决
- ...（如无则省略）
## 最近 commit
- ...（最近3条）
## 未提交变更
- ...（如无则"clean"）
## 更新时间
- YYYY-MM-DD HH:mm
```

### 3. 写入状态文件

将归纳内容写入 `_tmp/sessions/<session-name>.md`，**完整覆盖**（不追加）。

### 4. 确认

输出：`✅ 状态已写入 _tmp/sessions/<session-name>.md`

---

## 注意

- 状态文件是**快照**，不是日志——每次覆盖写，保持最新状态
- 如果不确定 session-name，询问用户一次，格式：`这个会话负责哪个模块？（用于命名状态文件）`
- 不需要完美，粗粒度的状态比没有状态好
